# Natural Language API Test Automation

This project is a Python script that automates API testing by translating natural language instructions into executable API requests. It uses OpenAI's GPT to understand the instructions and map them to a predefined Postman collection.

## Overview

The script reads a series of commands from a CSV file (e.g., "Get all users"), finds the corresponding API request from a Postman collection, executes it (in a mocked environment), and writes the results back to a new CSV file. This allows for writing API tests in plain English rather than code.

## Features

- **Natural Language Processing:** Leverages OpenAI's `gpt-3.5-turbo` to understand test instructions.
- **Postman Integration:** Uses a standard Postman collection file to define API endpoints.
- **CSV-Based I/O:** Reads test cases from a CSV file and outputs the results to another CSV.
- **Mocked Execution:** Includes a mocked API execution layer for demonstration without needing a live backend.
- **Extensible:** Can be adapted to work with live APIs by modifying the execution function.

## How It Works

1.  **Load Inputs:** The script starts by loading the natural language instructions from `input.csv` and the API definitions from `postman_collection.json`.
2.  **Instruction-to-API Mapping:** For each instruction, it sends a prompt to the OpenAI API, asking it to choose the most appropriate API request from the names listed in the Postman collection.
3.  **API Request Execution:** The script then executes the chosen API request. The current implementation uses a **mocked** function that returns sample data based on the request's URL and method.
4.  **Output Generation:** The response (or any error) from the execution is captured and written into the `output` and `error` columns of a new file, `output.csv`.

## Prerequisites

- Python 3.x
- An OpenAI API key.

## Installation & Setup

1.  **Clone the repository:**
    ```bash
    git clone <repository-url>
    cd <repository-directory>
    ```

2.  **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

3.  **Set up your environment variable:**
    You must set your OpenAI API key as an environment variable named `OPENAI_API_KEY`.

    -   **macOS/Linux:**
        ```bash
        export OPENAI_API_KEY="YOUR_OPENAI_API_KEY"
        ```
    -   **Windows:**
        ```bash
        set OPENAI_API_KEY="YOUR_OPENAI_API_KEY"
        ```
    > **Note:** Replace `"YOUR_OPENAI_API_KEY"` with your actual key.

## Usage

To run the script, simply execute `main.py` from your terminal:

```bash
python main.py
```

The script will process the `input.csv` and generate an `output.csv` file with the results.

## File Descriptions

-   `main.py`: The core Python script that orchestrates the entire process.
-   `input.csv`: The input file containing natural language instructions for the tests. You can add your own instructions here.
-   `output.csv`: The output file where the results of the test execution are stored. This file is generated by the script.
-   `postman_collection.json`: A standard Postman collection file that defines the available API requests.
-   `requirements.txt`: A list of the Python packages required to run the script.
-   `README.md`: This file.
